# โครงสร้างโปรเจกต์

## หน้าจอและงาน UX/UI

ไฟล์เว็บไซต์อยู่ที่ `src/main/resources/static/`

| ตำแหน่ง | หน้าที่ |
| --- | --- |
| `index.html` | หน้าแรกและข้อมูลทั่วไป |
| `login.html` | หน้าเข้าสู่ระบบ |
| `staff.html` | พื้นที่ทำงานเจ้าหน้าที่ |
| `teacher.html` | พื้นที่ทำงานอาจารย์ |
| `assets/css/style.css` | สไตล์พื้นฐานที่ใช้ร่วมกัน |
| `assets/css/workspace.css` | รูปแบบพื้นที่ทำงานร่วมกันของเจ้าหน้าที่และอาจารย์ |
| `assets/css/login.css` | รูปแบบเฉพาะหน้าเข้าสู่ระบบ |
| `assets/css/staff.css` | รูปแบบเฉพาะหน้าเจ้าหน้าที่ |
| `assets/css/teacher.css` | รูปแบบเฉพาะหน้าอาจารย์ |
| `assets/js/script.js` | การทำงานของหน้าแรก |
| `assets/js/status.js` | ฟังก์ชันสถานะเอกสารที่ใช้ร่วมกัน |
| `assets/js/login.js` | การเข้าสู่ระบบ |
| `assets/js/staff.js` | การทำงานฝั่งเจ้าหน้าที่ |
| `assets/js/teacher.js` | การทำงานฝั่งอาจารย์ |
| `images/` | ตราสัญลักษณ์และรูปภาพ |

หน้าเจ้าหน้าที่และอาจารย์โหลดสไตล์ตามลำดับ `style.css` → สไตล์เฉพาะหน้า → `workspace.css` เพื่อคงรูปแบบปัจจุบันไว้

แก้โครงสร้างและข้อความใน HTML, รูปแบบใน CSS และพฤติกรรมใน JavaScript โดยรักษา `id` และชื่อฟังก์ชันที่หน้า HTML เรียกใช้งาน

## พรีวิวภายในเครื่อง

เปิด `ui-preview.html` ผ่าน Live Server แล้วเลือกบทบาทด้านบน ไฟล์นี้ใช้ข้อมูลจำลองและถูกยกเว้นจาก Git จึงไม่ติดไปในการ push ตามปกติ แก้หน้า HTML และไฟล์ใน `assets/` แล้วกดโหลดการแก้ไขล่าสุด

## ระบบหลังบ้าน

- `src/main/java/com/example/demo/`: จุดรับคำขอ ข้อมูลเอกสาร ผู้ใช้ การเชื่อมฐานข้อมูล และ S3
- `src/main/resources/application.properties`: การตั้งค่าระบบ
- `src/test/`: การทดสอบ Java
- `pom.xml`: ส่วนประกอบและการสร้างแอปด้วย Maven
- `target/`: ผลลัพธ์จากการสร้างแอป ไม่ใช่ไฟล์ต้นฉบับสำหรับแก้ไข

ชื่อและที่อยู่หน้า HTML เดิมยังคงเดิม การจัดไฟล์ส่วนหน้าไม่เปลี่ยนเส้นทาง API หรือกติกาสิทธิ์ผู้ใช้
